# ReChzzk — 저지연 치지직 안드로이드 클라이언트

치지직 앱과 같은 구성(홈 · 팔로잉 · 클립 · 탐색)의 비공식 개인용 클라이언트입니다. **방송 지연을 최소화**하는 데 초점을 맞췄습니다.

## 설치
- **[ReChzzk-1.0.2.apk 다운로드](release/ReChzzk-1.0.2.apk?raw=1)** 후 휴대폰에 설치합니다 (Android 8.0 이상). "출처를 알 수 없는 앱" 허용이 필요합니다.
- 설치 후 설정(오른쪽 위 프로필)에서 **배터리 최적화에서 제외하기**를 눌러야 삼성 기기에서 방송 알림이 늦지 않습니다.
- 직접 빌드: Android Studio로 폴더를 열거나 `./gradlew assembleRelease`를 실행합니다 (JDK 17 이상, Android SDK 35 필요).

## 지연을 줄이는 방법
| 항목 | 설정 |
|---|---|
| 프로토콜 | 치지직이 제공하는 **LL-HLS**(`mediaId=LLHLS`) 주소를 사용합니다. 1초 단위 파셜 세그먼트와 블로킹 리로드를 지원합니다. |
| 시작 버퍼 | 재생 시작 300ms, 끊긴 뒤 재시작 800ms (ExoPlayer 기본값은 2.5초/5초) |
| 목표 지연 | 초저지연 1.5초 / 저지연 2.5초(기본) / 안정은 서버 권장값 3.05초 / 호환은 일반 HLS |
| 따라잡기 | 뒤처지면 최대 1.08~1.15배속으로 재생해 목표 지연으로 자동 복귀하고, 끊길 때마다 목표를 250ms씩 늘립니다. |
| 재개 | 일시정지 후 다시 재생하면 라이브 엣지로 점프합니다. 크게 밀리면 **"실시간으로"** 버튼이 나타납니다. |

플레이어 상단의 `지연 X.X초`는 세그먼트 생성 시각(PROGRAM-DATE-TIME)과 기기 시계를 비교한 값입니다. 따라잡는 중에는 배속도 함께 표시됩니다.

## 기능
- **자동 PIP**: 방송 중에 홈으로 나가면 바로 PIP로 전환됩니다. Android 12 이상은 홈 제스처와 함께 매끄럽게 전환되고, 11 이하는 `onUserLeaveHint`로 처리합니다.
- **라디오 모드(음성만 듣기)**: 영상을 끄고 소리만 받습니다. 앱을 나가도 알림창과 잠금화면에서 조작하며 계속 들을 수 있습니다.
- **홈 · 팔로잉 · 클립 · 탐색**: 공식 앱과 같은 구성입니다. 클립은 쇼츠처럼 세로로 넘기고, 다시보기와 클립은 HLS로 재생합니다.
- **채널 프로필**: 홈, 동영상(지난 방송/업로드, 최신·인기순), 클립(기간 필터), 커뮤니티, 정보(링크, 월간 통나무 랭킹) 탭과 팔로우·채널 알림(종) 버튼
- **채팅**: 이모티콘, 배지(매니저·구독·후원), 고정 메시지, 후원 강조, 클린봇 숨김을 지원하고, 위로 올려 읽는 중이 아니면 자동으로 따라 내려갑니다. 로그인하면 채팅을 보낼 수 있고, 가로 전체화면에서도 채팅창을 열고 닫을 수 있습니다.
- **통나무 파워**: 시청 중 생기는 통나무를 자동으로 받고, 통나무 투표에 참여할 수 있습니다.
- **치즈 후원**: 금액 확인 단계를 한 번 더 거친 뒤 후원합니다.
- **빠른 방송 알림**: 상시 알림 없이 약 1분마다 팔로우 채널을 확인하고, 채널 알림(종)을 켠 채널이 방송을 켰을 때만 알립니다. 재부팅 후 자동으로 다시 시작합니다. (깊은 절전 상태에서는 최대 10분 정도 늦어질 수 있음)
- 미니 플레이어, 해상도 선택, 전체화면, 채널 검색, `chzzk.naver.com/live/...` 링크 열기

## 구조
```
net/      Api.kt(엔드포인트) · Models.kt · Http.kt(WebView 쿠키를 OkHttp에 연결)
chat/     ChatClient.kt — WebSocket (cmd 100/10100 연결, 0↔10000 핑, 5101/15101 최근 채팅, 93101 채팅, 93102 후원, 3101 전송)
player/   PlayerHolder.kt(저지연 ExoPlayer 설정) · Session.kt(현재 재생·채팅 관리) · PlaybackService.kt(백그라운드)
notify/   LiveAlerts(알림 비교·발송) · FastAlerts(1분 간격 정확한 알람)
ui/       MainActivity(PIP·전체화면) · screens/* · components/*
```
`app/src/test/.../LiveApiTest.kt`는 실제 치지직 서버를 대상으로 API 파싱과 채팅 수신을 검증합니다.

## 주의
- 치지직 비공식 API를 사용하므로 서비스가 바뀌면 일부 기능이 동작하지 않을 수 있습니다.
- 통나무 자동 받기처럼 공식에서 제공하지 않는 자동화는 치지직 이용약관에 어긋날 수 있습니다.
- 개인 용도로만 사용해 주세요. 성인 인증이 필요한 방송과 유료 방송은 재생되지 않습니다.
